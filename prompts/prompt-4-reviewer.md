# Промпт №4 — AI-ревьюер: второй взгляд на каждую задачу

**Зачем:** автор кода — плохой судья своему коду, даже если автор — ИИ. Отдельный агент со свежим контекстом ловит то, что «замылилось»: несоответствие критерию приёмки, крайние случаи, секреты в коде. На CHATBOSS.PRO ревью проходит каждая задача — брак не доезжает до доски.

После промпта в `CLAUDE.md` появится раздел «AI-ревью», и каждая задача перед Done будет проходить проверку с приоритетами P0–P3.

```
Дополни CLAUDE.md разделом «AI-ревью» и с этого момента работай по нему при закрытии каждой задачи:

## AI-ревью
- Перед переводом задачи в Done запускай отдельного субагента-ревьюера. Передавай ему: критерий приёмки задачи и полный diff изменений (git diff по затронутым файлам).
- Чек-лист ревьюера: 1) соответствие критерию приёмки; 2) ошибки и крайние случаи — пустые данные, null, конкурентный доступ; 3) безопасность — секреты в коде, SQL-инъекции, незащищённые эндпоинты; 4) читаемость и стиль проекта.
- Каждое замечание — с приоритетом: P0 — блокирует закрытие задачи, P1 — исправить сейчас, P2 — можно отложить (создай под него задачу в Jira), P3 — вкусовщина, на моё усмотрение.
- P0 и P1 исправляй сразу и прогоняй ревью повторно. Задачу можно закрывать только с пустым списком P0/P1.
- Итог ревью добавляй в комментарий к задаче в Jira: сколько было замечаний и какие исправлены.

Запиши раздел, покажи итоговый CLAUDE.md и подтверди готовность.
```

## Лайфхак: бесплатный ревьюер из GitHub Copilot

Если код лежит на GitHub, второй взгляд можно получить бесплатно:

1. Пушьте ветку задачи и откройте Pull Request.
2. В списке Reviewers выберите **Copilot** («Request review from Copilot»).
3. Через минуту-две Copilot оставит построчные комментарии, как живой ревьюер.
4. Скормите их обратно исполнителю: «исправь замечания из ревью PR».
5. В настройках репозитория можно включить автоматическое Copilot-ревью каждого нового PR.

Честно про качество: под капотом ревью Copilot — GPT-4.1. По нашим прогонам она стабильно ловит уровень кода (типы, крайние случаи, очевидные баги, забытые проверки), архитектуру ловит хуже — для этого в полном конвейере у нас второй ревьюер. Тариф Copilot Free работает без карты, лимита запросов хватает на несколько ревью в день.
