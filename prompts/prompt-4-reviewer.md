# Промпт №4 — AI-ревьюер: второй взгляд на каждую задачу

Автор кода — плохой судья своему коду, даже если автор ИИ. Отдельный агент со свежим контекстом ловит то, что замылилось: несоответствие приёмке, крайние случаи, секреты в коде. На CHATBOSS.PRO ревью проходит каждая задача.

После промпта в `CLAUDE.md` появится раздел «AI-ревью», и каждая задача перед Done проходит проверку с приоритетами P0–P3.

```
Дополни CLAUDE.md разделом «AI-ревью» и работай по нему при закрытии каждой задачи:

## AI-ревью
- Перед Done запускай отдельного субагента-ревьюера со свежим контекстом. Дай ему критерий приёмки и diff изменений.
- Проверяй: соответствие приёмке; ошибки и крайние случаи (пустые данные, null, гонки); безопасность (секреты в коде, инъекции, открытые эндпоинты); читаемость и стиль проекта.
- Каждое замечание — с приоритетом: P0 блокирует Done, P1 исправить сейчас, P2 отложить (завести задачу), P3 вкусовщина.
- P0/P1 чини сразу и прогоняй ревью повторно. Закрывать задачу можно только с пустым P0/P1.
- Итог ревью — комментарием к задаче: сколько замечаний и что исправлено.

Запиши раздел, покажи CLAUDE.md и подтверди готовность.
```

## Лайфхак: бесплатный ревьюер из GitHub Copilot

Если код на GitHub — второй взгляд можно получить бесплатно:

1. Запушьте ветку, откройте Pull Request.
2. В Reviewers выберите **Copilot** («Request review from Copilot»).
3. Через пару минут он оставит построчные комментарии.
4. Отдайте их исполнителю: «исправь замечания из ревью PR».
5. В настройках репозитория можно включить авто-ревью каждого PR.

Под капотом — GPT-4.1: уровень кода (типы, крайние случаи, забытые проверки) ловит стабильно, архитектуру хуже — для неё в полном конвейере второй ревьюер. Тариф Copilot Free работает без карты.
