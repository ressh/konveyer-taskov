# Промпт №1 — научите ИИ вашей Jira

ИИ сам создаст `.env` (вы только впишете четыре значения), потом сделает разведку доски — статусы, переходы, задачи. Ничего в Jira не меняется.

Если на шаге 1 разведки ИИ показал имя вашего аккаунта — связка работает. Ошибка 401 — проверьте email и токен в `.env`.

```
Работаем с Jira через REST API v3 с Basic-авторизацией (email:токен). Доступы держим в файле .env в корне проекта: JIRA_BASE_URL, JIRA_EMAIL, JIRA_API_TOKEN, JIRA_PROJECT. Правило безопасности: API-токен никогда не выводи в чат, логи, код или коммиты — и не проси меня вставлять его в сообщения.

Шаг 0. Если файла .env нет — создай его с этими четырьмя полями-заглушками, проверь, что .env добавлен в .gitignore (нет — добавь), и скажи мне, что и куда вписать: адрес Jira, почту аккаунта, API-токен с id.atlassian.com и ключ проекта. Значения я впишу в файл сам. После этого остановись и дождись моего «готово».

Когда .env заполнен — сделай проверку связки и разведку моего проекта:
1. GET {JIRA_BASE_URL}/rest/api/3/myself — покажи имя аккаунта из ответа: это подтверждение, что соединение работает.
2. GET /rest/api/3/project/{JIRA_PROJECT}/statuses — какие типы задач и статусы есть на моей доске.
3. Поиск задач по JQL (project = {JIRA_PROJECT} ORDER BY created DESC) — покажи последние задачи: ключ, название, статус.
4. Возьми любую задачу и запроси GET /rest/api/3/issue/{ключ}/transitions — какие переходы между статусами доступны.

В конце дай сводку: аккаунт, статусы доски, доступные переходы и список задач в To Do. Пока ничего не меняй в Jira — это только разведка.
```
