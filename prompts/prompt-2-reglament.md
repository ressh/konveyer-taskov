# Промпт №2 — закрепите навык в системных настройках

ИИ запишет регламент работы с Jira в `CLAUDE.md` — файл памяти Claude Code. Навык будет действовать в каждой новой сессии.

После этого промпта проверьте: в корне проекта появился (или дополнился) `CLAUDE.md` с разделом «Работа с Jira», а `.env` числится в `.gitignore`.

```
Связка с Jira работает — теперь закрепи навык, чтобы он действовал в каждой новой сессии. Создай (или дополни) файл CLAUDE.md в корне проекта и запиши туда регламент:

## Работа с Jira
- Доступы — в .env: JIRA_BASE_URL, JIRA_EMAIL, JIRA_API_TOKEN, JIRA_PROJECT. Токен не выводить в чат, логи и код. Проверь, что .env добавлен в .gitignore, — если нет, добавь.
- Команда «возьми в работу {ключ задачи}» запускает полный цикл задачи:
  1. GET /rest/api/3/issue/{ключ} — прочитать название, описание и комментарии. Если критерий приёмки не указан — сформулировать его и показать мне перед началом работы.
  2. Перевести задачу в In Progress (POST /rest/api/3/issue/{ключ}/transitions).
  3. Выполнить задачу в коде проекта.
  4. Отдать результат на проверку отдельному субагенту-ревьюеру: соответствие критерию приёмки, ошибки, крайние случаи, стиль кода. Замечания исправить сразу, до закрытия задачи.
  5. Перевести задачу в Done (если на доске есть колонка Review или In Testing — использовать её) и оставить комментарий: что сделано, какие файлы затронуты.
- Если задача слишком крупная для одного цикла — сначала предложить разбить её на подзадачи в Jira и дождаться моего подтверждения.
- По команде «стоп» — аккуратно завершить текущий шаг и зафиксировать честный статус задачи в Jira.

Запиши регламент, покажи итоговый CLAUDE.md и подтверди готовность к работе.
```
